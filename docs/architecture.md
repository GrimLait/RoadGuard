# Архітектура системи «RoadGuard»

## 1. Загальний опис та архітектурний підхід
Для реалізації системи інтелектуального виявлення дефектів дорожнього покриття обрано **клієнт-серверну модульну архітектуру**, організовану у форматі **монорепозиторію (Monorepo)**. 

Такий підхід забезпечує:
* Зручність спільної розробки інтерфейсу, серверної частини та модуля комп'ютерного зору в одному просторі.
* Ізоляцію бізнес-логіки та простоту розгортання через Docker Compose.
* Нативну інтеграцію моделі машинного навчання YOLO без створення складних міжсервісних комунікацій.

---

## 2. Технологічний стек та його обґрунтування

### 2.1. Серверна частина (Backend API)
* **Технологія:** Python 3.11+, **FastAPI**, SQLAlchemy (ORM).
* **Обґрунтування:** Модель YOLO (Ultralytics) функціонує в екосистемі Python (PyTorch). Використання FastAPI дозволяє виконувати інференс моделі безпосередньо в обробниках запитів без затримок на мережевий IPC-обмін. Фреймворк є асинхронним, високопродуктивним та автоматично генерує інтерактивну документацію OpenAPI (Swagger).

### 2.2. Модуль комп'ютерного зору (AI / ML)
* **Технологія:** **YOLOv8 / YOLOv11** (PyTorch).
* **Обґрунтування:** Архітектура YOLO забезпечує детекцію дефектів у реальному часі (real-time inference). Реалізовано алгоритм подвійного порогу:
  * `< 15%` — автоматичне відхилення (спам/відсутність дефектів).
  * `15% – 84%` — сумнівна зона (направлення на модерацію людині).
  * `>= 85%` — висока впевненість (автоматичне підтвердження).

### 2.3. База даних (Database)
* **Технологія:** **PostgreSQL** із розширенням **PostGIS**.
* **Обґрунтування:** Надійна реляційна СУБД для забезпечення цілісності зв'язків між зверненнями, окремими рамками дефектів (DetectionResult) та аудитом дій модератора. Розширення PostGIS забезпечує роботу з геопросторовими індексами для швидкої фільтрації дефектів на карті за координатами.

### 2.4. Клієнтська частина (Frontend)
* **Технологія:** **React** (Vite, TypeScript), Tailwind CSS.
* **Робота з картами:** **Leaflet** (React-Leaflet) + OpenStreetMap.
* **Обґрунтування:** React забезпечує швидкий інтерактивний інтерфейс (SPA). Leaflet є безкоштовним, легким рішенням для відображення інтерактивної карти дефектів, кластеризації маркерів та відображення геозон без використання платних API (Google Maps).

### 2.5. Інфраструктура (DevOps)
* **Технологія:** **Docker, Docker Compose**.
* **Обґрунтування:** Уніфікація середовища розробки. Запуск клієнта, бекенда та бази даних здійснюється однією командою: `docker-compose up`.
